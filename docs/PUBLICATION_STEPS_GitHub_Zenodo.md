# Software archive and citation

The author-approved source repository is public at
https://github.com/ebhebh/psg-audio-benchmark. Zenodo concept DOI:
https://doi.org/10.5281/zenodo.23101023. The first archived snapshot,
version 1.0.0rc1, has version DOI https://doi.org/10.5281/zenodo.23101024.

The 1.0.0rc2 snapshot corrects the internal SHA-256 manifest and package
metadata; it does not change the scientific analyses. The concept DOI resolves
to the latest published version. Cite the version DOI for a reproducible
version-specific reference, or the concept DOI when referring to the software
across versions. Do not cite the associated manuscript as published: it has
not been submitted or accepted.

The software DOI does not replace citation of the source dataset. Cite the
Science Data Bank dataset (DOI 10.57760/sciencedb.19070, version V5) separately.

## Scope

The archive contains code, configurations, aggregate publication outputs and
reproduction documentation. It excludes raw PSG/audio, patient-level and
window-level data, ethics documents, and privately obtained reference PDFs.
Original code is MIT-licensed. Dataset-derived aggregate outputs carry the
separate CC BY 4.0 attribution notice in `LICENSE_DATA.md`.
